# Presentation kit

The presentation is designed for three speakers and approximately 15 minutes:

- slides 1–5: Simone;
- slides 6–10: Vlad;
- slides 11–15: third group member.

Files:

- `FDL_Speech_Commands.pptx`: editable source deck;
- `FDL_Speech_Commands.pdf`: eLearning submission and offline fallback;
- `presentation_script.md`: slide-by-slide timing, hand-offs, and speaker notes;
- `q_and_a.md`: likely defence questions with evidence-backed answers.

Before submission, fill in the visible full names, practise two complete timed runs,
and verify that every speaker can explain the split protocol, model-selection rule,
augmentation trade-off, test confidence intervals, and failure cases. The oral delivery and
all slides must remain in English.

The final presentation should be run from the PDF for maximum portability. Keep the PPTX only
as an editable backup and use the offline demo instructions in `docs/demo_guide.md` if the
professors ask for a live prediction or a qualitative audio example.
