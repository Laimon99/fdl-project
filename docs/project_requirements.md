# Project delivery requirements

This file records the operative constraints supplied by the group. It is a checklist,
not a substitute for announcements on the official eLearning platform.

- Official exam and presentation: **15 September 2026**.
- Submission deadline: **8 September 2026 at 23:59 Europe/Rome**.
- Group: three students; approximately five minutes and five slides per student.
- Slides and oral presentation: English.
- Submit directly on eLearning: slide deck as PDF, Python code, trained model/weights.
- Google Drive is allowed only for weights that exceed the upload limit, not for code or slides.
- Cover problem, group, data analysis, proposed solution, quantitative and qualitative
  positive/negative results, alternative experiments, and failed experiments when relevant.
- A pretrained model may be used only as a comparison or feature extractor; the project must
  contain a substantial model designed and trained by the group.
- Speech Commands is one of the professor-proposed datasets, so no external-dataset approval
  is required.
- Submitted work must be original and understandable by every group member.
